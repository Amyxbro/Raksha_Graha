# Raksha Graha

Scalable Flutter/Firebase project blueprint and source foundation for Customer and Admin apps.

## Current source includes
- Customer app foundation
- Nepali/English language selection
- Login UI for mobile/email OTP flows
- Home, Horoscope, Chat, Stories, Profile navigation
- Profile post/story entry points
- QR/Barcode scanner entry point
- Separate Kids section entry point
- Admin app role foundation
- Firebase security-rule design document

## Important
This package is source code and architecture. The current environment does not have the Flutter SDK, so an APK cannot be compiled here. Run `flutter pub get` and `flutter run` in each Flutter app on a machine with Flutter installed.
