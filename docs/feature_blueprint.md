# Raksha Graha master feature blueprint

Customer: auth, profile, birth details, current location privacy, home, BS+AD, daily hub, horoscope, festival popup, notifications, customer-admin chat, customer-customer chat, posts, 24h stories, share/refer, My QR, universal QR/barcode scanner, separate Kids section.

Admin: Main Admin + Admin 1 + Admin 2, role permissions, customer chat, content, daily hub, festival, notifications, users, suggestions, admin chat. Customer-customer conversations are Main Admin-only.

Chat media: in-chat camera, gallery, voice, file; original/high/data-saver photo modes planned. Audio/video calls are future-ready.

Kids: separate module with parent controls, no direct kid-to-kid messaging, stricter privacy.

Future: AI astrologer, Kundali, consultation, payments, subscriptions, games, quiz, rewards, analytics, ads.
